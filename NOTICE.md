# Credits

- `tools/bba.py` is a Python port of the archive format implementation from
  [S7Packer](https://github.com/Eisenmonoxid/S7Packer) by **Eisenmonoxid** (MIT License).
  The original C# tool is the reference for the `.bba` container used by The Settlers 7.
- [S7Patcher](https://github.com/Eisenmonoxid/S7Patcher) by the same author is a
  separate, complementary tool (dev mode, DLC unlock, bug fixes).

modifies a copy of the game you already own, on your own machine.
